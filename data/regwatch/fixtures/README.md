# Regulatory Watch fixtures

Every file here is **synthetic**: written by hand in the shape of RBI's pages and feeds so the
Regulatory Watch tests run offline. None is a copy of a real RBI document. Circular numbers use the
fictitious year range `2099-2100` (for example `RBI/2099-2100/901`) so they cannot be mistaken for
real ones, and no file states a real regulatory value.
