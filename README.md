# Abhiyogah

An RBI complaint-compliance engine. Banks send complaint events; the engine returns deadlines,
breaches, compensation and required actions, each backed by a replayable decision record that cites
the RBI clause, its version and the calendar used.

Status: in development. Not legal advice; the bank owns every final decision.
